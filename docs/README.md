>

>
> Manage clients, track pipeline, generate reports, auto-sync

## 特点 Features

| 功能 Feature | 说明 Description |
|---|---|
| 📱 快速录入 Quick Add | `/add` 两步添加客户 / 2-step client add |

| 🏢 团队分组 Teams | 每组独立论坛，自动数据隔离 / Per-team forums |

| 🤖 RAG 搜索 | 语义搜索客户+SOP文档 |

## 快速开始 Quick Start

1. 在 Telegram 找到 **@qianhub_records_bot**
2. 发送 `/start` 注册 / Send `/start` to register
3. 或者 `/bind 你的名字` 绑定已有账号 / Or `/bind your_name` to link existing account
4. 开始使用 `/add` 添加客户 / Start with `/add` to add clients
